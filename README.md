# Piktorio

ターン制シミュレーションゲーム — GitHub Pages 対応・サーバレス。

## プレイ

**https://paijp.github.io/piktorio/**

---

## ゲーム概要

20×20〜40×40 マスのマップをプレイヤーが探索し、pik（赤・青・黄の小生物）を操作して ヒビ壁を破壊していくターン制シミュレーション。

---

## ターン構造

```
プレイヤーターン
  └─ 移動フェーズ（最大3マス）
  └─ アクションフェーズ（pikの置く／拾う）
pikターン        ← ヒビ壁にダメージ処理
敵ターン         ← TODO
```

---

## マス種別

| 種別 | 色 | 説明 |
|---|---|---|
| 通路 (walk) | 緑 | プレイヤー通行可。pikを置ける・拾える |
| 壁 (wall) | 茶色 | 通行不可・操作不可 |
| ヒビ壁 (cracked) | 暗い茶色 | 通行不可・pikを置ける（HP100） |
| 赤マス (red) | 赤 | 通行不可・赤pikのみ置ける |
| 青マス (blue) | 青 | 通行不可・青pikのみ置ける |
| 黄マス (yellow) | 黄 | 通行不可・黄pikのみ置ける |
| 赤ヒビ壁 (red_cracked) | 赤（ヒビあり）| 通行不可・赤pikのみ置ける（HP40）。HP0→通路＋連鎖 |
| 青ヒビ壁 (blue_cracked) | 青（ヒビあり）| 通行不可・青pikのみ置ける（HP40）。HP0→通路＋連鎖 |
| 黄ヒビ壁 (yellow_cracked) | 黄（ヒビあり）| 通行不可・黄pikのみ置ける（HP40）。HP0→通路＋連鎖 |

### ヒビ壁の耐久力表示

ヒビ壁の中央に円グラフで耐久力を表示。

- HP 100%：完全な白い円弧
- HP <100%：扇形の輪郭線のみ（塗り潰しなし）。反時計回りに欠けていく
- HP 0：通路に変化

### 色ヒビ壁の連鎖破壊

赤・青・黄のヒビ壁がHP0になると、上下左右につながっている同色の（ヒビでない）色マスも連鎖的に通路へ変化する。

---

## pik（ピック）

赤・青・黄の3種類。マップ上に最大100体まで存在できる。

- プレイヤーが踏んだ通路マスのpikは自動回収
- マップ上のpikはマスの隅に数字で表示（左上=赤、右上=黄、左下=青）
- プレイヤーの持ちpikも同じレイアウトで表示

---

## 移動フェーズ

- 1ターンに最大3マス移動
- プレイヤーは **通路マスのみ** 通行可能
- 画面UI：プレイヤーの上下左右に **△矢印** → タップで移動
- プレイヤー中央の **✓ボタン** → タップで移動スキップ→アクションフェーズへ
- キーボード：矢印キー / WASD で移動、スペース / Enter でスキップ
- 移動フェーズ中はpik操作不可
- タップした矢印が一瞬大きくなる（フラッシュ）

---

## アクションフェーズ

プレイヤーの周囲8マス（斜め含む）に対して操作可能。  
各マスの4隅にボタンが表示される（押せるものだけ表示）。

| 位置 | 操作 | 条件 |
|---|---|---|
| 左上（赤背景）| 赤pikを1個置く | 持ち赤pik≥1、対象マスが赤/ヒビ/通路 |
| 右上（黄背景）| 黄pikを1個置く | 持ち黄pik≥1、対象マスが黄/ヒビ/通路 |
| 左下（青背景）| 青pikを1個置く | 持ち青pik≥1、対象マスが青/ヒビ/通路 |
| 右下（灰背景 ×）| 全pik回収 | 対象マス（通路・色マス）にpikがある |

- 色マスには対応する色のpikのみ置ける（ヒビ壁も同様）
- プレイヤー自身のいるマスにはボタンは表示されない
- プレイヤー中央の **✓ボタン** → タップでターン終了
- ボタンを押すと一瞬大きく表示される（フラッシュ）

---

## pikターン

各ヒビ壁にpikが置かれていると、以下のダメージが入る：

```
ダメージ = 赤pik数 × 2 + 青pik数 × 1 + 黄pik数 × 1
```

HP が 0 になると通路（緑）に変化。色ヒビ壁の場合は連鎖破壊が発生する。

---

## 画面表示

- **メインマップ**：常に 10×10 マスを表示（プレイヤー中心、スクロール）
- **ミニマップ**：右下に全マップを縮小表示（4px/マス）
  - 訪問済みマスはタイル色で表示、未訪問は黒
  - スタートマスは白で表示
  - pikのいるマスに色ドット
  - プレイヤー位置に白丸
- **霧（Fog of War）**：マップ全体が見える円形範囲を初期表示。移動で徐々に探索
- スタートマスには白い枠線が付く

## ファイル構成

```
piktorio/
├── piktorioengine.js   # ゲームエンジン（全マップ共通）
├── index.html          # マップデータ＋HTML
└── README.md
```

マップを追加するときは `index.html` を複製して `mapData` を書き換えるだけ。

---

## マップデータの書き方

```js
const W  = { type: 'walk' };
const WL = (r,b,y) => ({ type:'walk', piks:{red:r,blue:b,yellow:y} });
const BK = { type: 'wall' };
const CR = { type: 'cracked' };           // ヒビ壁（HP100）
const RC = { type: 'red_cracked' };       // 赤ヒビ壁（HP40）
const BC = { type: 'blue_cracked' };      // 青ヒビ壁（HP40）
const YC = { type: 'yellow_cracked' };    // 黄ヒビ壁（HP40）
const R  = { type: 'red' };
const B  = { type: 'blue' };
const Y  = { type: 'yellow' };

const mapData = {
  playerStart: [行, 列],  // 0-indexed
  tiles: [
    [ BK, BK, ... ],      // 行0（外周は壁推奨）
    [ BK,  W, ... ],      // 行1
    // ... N行 × N列
  ],
};
```

## エンジン公開 API

```js
Piktorioengine.init(mapData)           // 初期化
Piktorioengine.movePlayer(dr, dc)      // 移動 (-1/0/1)
Piktorioengine.cellAction(r,c,zone)    // アクション ('topleft'|'topright'|'bottomleft'|'bottomright')
Piktorioengine.endPlayerTurn()         // ターン終了
Piktorioengine.skipMove()              // 移動スキップ
Piktorioengine.handleCanvasClick(e)    // クリック／タップイベント処理
```
